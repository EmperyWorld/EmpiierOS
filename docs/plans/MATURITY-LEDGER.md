## Status vocabulary

| Status | Meaning |
|---|---|
| `verified-real` | Behavior was observed through the Shell, Runtime, substrate, and a representative target. |
| `partial` | Some real probing or behavior exists, but the complete contract is not proven. |
| `simulated` | The implementation changes test/local state without performing the claimed OS operation. |
| `disabled` | Intentionally unavailable in the production profile because its security or substrate contract is incomplete. |
| `not-implemented` | No implementation that satisfies the contract exists. |

`Done`, `Wired`, a green badge, a route, a state file, or a passing unit test is
not a maturity status.

## Promotion rule

A row may move to `verified-real` only in the same change that records:

1. the exact implementation paths,
2. positive and negative automated evidence,
3. image/substrate evidence where applicable,
4. representative metal evidence,
5. remaining exclusions.
